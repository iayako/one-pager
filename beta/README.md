# Бета: подбор авто с расчётом стоимости

Демо-страница «как на дром.ру»: единая форма-панель с полями марка / модель /
поколение / год / топливо / КПП / двигатель / цена. Поколение выбирается в
модальном окне по карточкам с фото (как «Любое поколение» на дроме). Топливо и
КПП фильтруют список двигателей; итог — ориентировочная стоимость под ключ
(Train / Track).

## Как устроено

- **Каталог** — `catalog.js`: Toyota и Honda, популярные модели для импорта из Японии.
  Данные модификаций собраны вручную для демо и **требуют выверки** перед боевым запуском.
  Фото поколений — Wikimedia Commons (свободные лицензии), хотлинк через `Special:FilePath`.
- **Формула расчёта** — импортируется из прод-`../calc-core.js`, отдельной копии нет:
  бета всегда считает так же, как основной калькулятор.
- **Курсы** — `../api/rates_snapshot.php`; активная схема формул — `../api/calculation_config.php`
  (та, что публикуется из админки). При недоступности API — расчёт по примерным курсам
  с предупреждением.
- Страница закрыта от индексации (`noindex, nofollow`) и не линкуется с главной.

## Деплой

Workflow `.github/workflows/deploy-beta.yml`: push в ветку `feature/car-picker-beta`
выкладывает **только папку `beta/`** в `/var/www/one-pager/beta/` → https://uus-avto.ru/beta/.
Прод-файлы не затрагиваются.

⚠️ В `deploy-timeweb.yml` (main) должен быть `--exclude "beta/"`, иначе прод-деплой
с `--delete` удалит эту папку на сервере.
